# odin-recipes

In this project, I am to make a recipe website displaying basic HTML skills. It is a simple one, consisting of an index, as well as links to the recipes. This displays the use of lists, links, images, as well as git manipulation. Habits of making proper commit comments, as well as HTML minutiae, will also be tested. 

## Project Retrospective

The use of HTML tags and elements for links, lists, attachments, and text went easily. Proper file and directory management was observed. Git manipulation required a brief look at the Git Basics lesson at the start, for repo cloning. Specific searches were made for removing files added to staging area or local commits. Habits in making atomic commits and commit comments were improved, easily taking as much time as the actual HTML manipulation. Attributions of images used and recipes adapted took more time than anticipated.

Attribution of images and recipes took the most effort. For instance, the proper tags for image caption attributions, that is `<figure>/<figcaption>`, rather than `<h6>`. The proper format and links for attributing images, that is the page where it was downloaded, the source, and the license. An example, downloaded X from Wikimedia Commons, by Y Flickr, licensed under Z. Good security habits such as the use of `rel="noopener noreferrer"` were honed.

Recipe attribution was more complicated. Rather than a simple set of links, specific use of terms such as "Adapted", not just from, are used to reduce copyright issues. This requires rewording the steps. Even then, it is a gray area. Given the educational purposes of this exercise, it should be fine, though greater care must be taken if one is to commercialize it. 

In summary, use of HTML tags & elements went well, as with the file and directory management. Meanwhile, git manipulation improved, needing some browsing. Attribution took the most time, from the details of image attribution to the additional work involved in recipe attribution.
